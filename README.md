# Construção de Páginas Web

Repositório desenvolvido para a disciplina **Construção de Páginas Web** do CEDERJ, contendo exercícios práticos, atividades propostas e páginas desenvolvidas utilizando HTML e CSS.

## 📋 Objetivo

Este projeto reúne os exercícios e atividades realizados durante a disciplina, com foco nos conceitos fundamentais de desenvolvimento web, incluindo:

- Estruturação de páginas com HTML;
- Criação de formulários;
- Navegação entre páginas;
- Organização de conteúdo;
- Utilização de imagens;
- Estilização com CSS;
- Desenvolvimento de páginas estáticas.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Javascript

## 📚 Conteúdo

### Semana 1

Exercícios introdutórios da disciplina abordando:

- Estrutura básica de documentos HTML;
- Uso de títulos, parágrafos e listas;
- Inserção de links;
- Organização de conteúdo em páginas web.

### AD01

Atividade avaliativa composta por páginas relacionadas à empresa fictícia **Doremi Solfá Móveis**.

Funcionalidades desenvolvidas:

- Página inicial;
- Catálogo de produtos;
- Cadastro de clientes;
- Página de encomendas;
- Navegação entre páginas;
- Aplicação de estilos CSS;
- Utilização de imagens para apresentação dos produtos.

## ▶️ Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/ConstrucaoDePaginasWEB.git
```

2. Acesse a pasta do projeto.

3. Abra qualquer arquivo `.html` diretamente no navegador.

Exemplo:

```text
AD01/Questão1/index.html
```

ou

```text
AD01/Questão2-6/DoremisolfaMoveis.html
```
